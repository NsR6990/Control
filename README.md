# کنترل — اتاق فرمان

این مخزن، دفتر کار **نظارت** است. خودش چیزی نمی‌سازد؛ کارش این است که
بداند در پروژه‌های تحت نظر چه گذشته، چه تصمیمی گرفته شده و چرا، و قدم
بعد چیست.

## چرا جداست

نظارت و ساخت دو کار متفاوت‌اند و نباید در یک مخزن قاطی شوند:

- جلسهٔ **سازنده** فقط مخزن پروژه را می‌بیند. حواسش به کد است و بس.
- جلسهٔ **ناظر** این مخزن را می‌بیند به‌علاوهٔ مخزن پروژه. تصمیم می‌گیرد،
  بریف می‌نویسد، خروجی سازنده را می‌سنجد، و صف کار را نگه می‌دارد.

قبلاً این دفتر داخل خود مخزن پروژه بود (`.control/`) و هر بار باید به
جلسهٔ سازنده می‌گفتیم به آن دست نزند. حالا لازم نیست: چیزی که آنجا نیست،
اشتباه خوانده نمی‌شود.

## فایل‌ها

- `CLAUDE.md` — قواعد جلسهٔ ناظر. اول از همه خوانده می‌شود.
- `nazer.md` — دفتر کار: کجا ایستاده‌ایم، صف زنده، کارنامهٔ اشتباه‌ها،
  و تاریخچهٔ تصمیم‌ها.

## پروژه‌های تحت نظر

- **چرتکه** (`NsR6990/Zehnyar`) — اپ شخصی پیگیری هر چیزی که تاریخ دارد.
